# HH Goa FrameForge

> Create your HH Goa 2026 builder identity in seconds.

HH Goa FrameForge is a lightweight web tool for turning an ordinary photo into a personalized, share-ready **HH Goa 2026 Builder ID Card** or **profile picture frame**.

Upload a photo, add your name and stack, get a generated builder title, and instantly create a branded graphic ready to download or share on X.

No account.  
No signup.  
No complicated editor.  
Just upload → personalize → generate → share.

---

## ✨ Features

### 🪪 Builder ID Card

Create a personalized HH Goa 2026 event-style builder card containing:

- Profile photo
- Builder name
- Stack / role
- Generated builder title
- HH Goa 2026 branding
- Event-inspired visual treatment
- Share-ready composition

The output is designed primarily for social sharing rather than physical printing.

### 🖼️ Profile Picture Frame

Optionally generate an HH Goa 2026 profile picture frame that wraps around an uploaded photo while keeping the photo itself front and center.

### 📸 Upload Any Photo

The generator is designed to handle real-world photos without requiring users to manually crop them first.

Supported formats include:

- JPG / JPEG
- PNG
- HEIC / HEIF

It should gracefully handle:

- Portrait photos
- Landscape photos
- Square photos
- Off-center subjects
- Different aspect ratios
- Phone camera images
